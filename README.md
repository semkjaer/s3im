# s3im

An ROI-aware variant of the structural similarity index measure (SSIM), with notebooks and data for image-quality experiments.

## Project layout

```text
.
|-- README.md
`-- ssim/
    |-- util/                  # SSIM implementation, image helpers, analysis script
    |-- analysis.ipynb         # Image-quality analysis and images
    |-- OneDrive_1_5-19-2025/  # Source photoacoustic images for the analysis script
    |-- cropped_grayscale/     # Cropped images generated by the analysis script
    |-- created_images/        # Example and visualization images
    |-- data/, tid2013/, ...   # Additional datasets and experiment assets
```

## Set up (Windows PowerShell)

### Intall packages
Python 3.10.8 was used for the project.

```powershell
cd .\ssim
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

### Download and unzip data
powershell code below, also available at https://drive.google.com/file/d/1FZfBi4vRhBGA5gJghRrYqDzr9_NLfOLH/view?usp=drive_link

```powershell
gdown 1FZfBi4vRhBGA5gJghRrYqDzr9_NLfOLH -O dataset.zip

if ($LASTEXITCODE -eq 0) {
    Expand-Archive -Path .\dataset.zip -DestinationPath .\ssim -Force
    if ($?) {
        Remove-Item .\dataset.zip
        Write-Host "Dataset extracted successfully; ZIP removed."
    }
}
```

## Use the project

- **Run the prepared analysis:** From the `ssim` directory with the environment activated, run `python util\run_analysis.py`. It reads PNG images under `OneDrive_1_5-19-2025\`, creates cropped grayscale images in `cropped_grayscale\`, evaluates image distortions, and writes `image_quality_metrics_analysis.parquet` in the current directory. The run may take some time (>1hr).
- **Explore or adapt the images/notebook:** Open  `analysis.ipynb`\ in VS Code or Jupyter.
